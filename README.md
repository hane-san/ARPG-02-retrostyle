# 潮環群島 — TIDAL ATLAS

『英雄叙事詩』の素材と操作感を活かして制作する、独立した**2D探索RPG実験版**です。敵、攻撃、ターン制はありません。お台場を連想させる人工島と連絡橋を舞台に、古城、港町、森林、展示施設、近未来都市を自由に歩きます。

- **移動**: 地形上をタップ／クリックすると、非表示の32pxグリッド上でA*経路探索し、自動で徒歩移動。長い橋も終点まで歩きます。移動中のタップで目的地を変更できます。
- **視点**: カメラ自動追従。ドラッグで見回す／「自分へ」で戻す。ホイールや＋／－でズーム。PCでは矢印キー・WASDにも対応。
- **NPC**: 村人をタップすると近くまで歩いてから会話。建物をタップすると入口まで歩いて解説を読みます。
- **世界**: 4つの広い島と4本の橋がロードなしにつながるフィールド。ミニマップと各所の発見ログ。
- **音楽**: [hane-san/SRPG](https://github.com/hane-san/SRPG) から元の `music.js` と `audio.js` を直接コピー。6マップ×敵味方2曲＋7テーマ×2曲＝計26曲をメニューで切替。Web Audio API合成なので音声ファイルや通信は不要。元のゲームとは異なるlocalStorage名前空間を使用。
- **独立性**: 元のSRPGリポジトリは変更しません。ゲーム画像はSRPGの32px Canvas色調・ユニット描画を参考にした新規のフィールド専用ドット描画です。

## 起動

`index.html` をローカルHTTPサーバーで配信してください（ES Modulesのため `file://` は非推奨）。

```sh
python3 -m http.server 4173
# http://localhost:4173
```

GitHub Pages はこのリポジトリで Pages を有効にすると `https://hane-san.github.io/fantasy-adventure-test/` で公開できます。現在はデザイン・操作の試作であり、戦闘・クエスト進行・セーブデータは未実装です。

## ファイル
- `world.js`: 島・橋・地形・施設・村人・経路探索（UI非依存）
- `game.js`: Canvas 2D描画／カメラ／入力／UI・会話・音楽連携
- `music.js` / `audio.js`: SRPG側と同一の楽曲・効果音ロジック
- `tests/world.test.mjs`: 橋経由の全域到達性・障害物・長距離移動経路の検証

**実験用です。** 『英雄叙事詩』の製品開発とは切り離しています。
