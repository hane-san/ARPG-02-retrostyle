# 潮環群島 × 星風回廊 — TIDAL ATLAS

**独立した2DオープンワールドRPGの実験版。** お台場の人工島・連絡橋・海辺をモチーフに、古い城、森と社、異国情緒の港町、白い展示都市、ネオンの近未来地区が連続する、歩くためのブラウザゲームです。

戦闘、敵、ターン制、キャラクター選択、攻撃／待機コマンドはありません。『英雄叙事詩』側のゲームとは完全に独立した実験です。

**開発・引継ぎの入口**： [AGENTS.md](AGENTS.md)（ChatGPT/Codex/Claude Code共通の契約）・[開発手順](docs/DEVELOPMENT.md)・[設計](docs/DESIGN.md)・[採用判断](docs/DECISIONS.md)・[残課題](docs/ROADMAP.md)・[品質検証](docs/QA.md)。

## 主な実装

- **シームレスなフィールド**：164×120（計19,680タイル）の広さ。４地区「風環の庭」「白磁の未来都」「潮騒の旧港」「蒼光の新港」が、海上の４本の連絡橋と、星風回廊へ渡る２本の橋がつながります。マップ切替・ローディングはなし。地区内にも16の景観小エリア（琥珀の林・苔むす遺構・ガラス庭園・赤瓦の街区・発光植物園など）を設け、徒歩中に風景の表情が頻繁に変化します。
- **移動だけに集中**：隠れた32pxグリッドとA*経路探索を使用。地形や橋をタップすると、自動で道を探して長距離でも少し速めにてくてく歩きます（約6.15タイル／秒）。小さな足音はSE設定に従い再生します。歩数ポップアップは非表示。戦術マス、移動範囲、ターン表示はなし。途中で目的地を変えられます。
- **フィールド描画**：Canvas 2Dによるドット絵地形、海、水面、樹木、古城、帆船桟橋、観覧輪、軌道塔など。主人公のスプライト描画は [SRPGのrender.js](https://github.com/hane-san/SRPG-01-FEstyle/blob/main/render.js) の描画処理から抽出して使用（戦術UI、HP表示は除外）。色・地形の方向性も参考にしています。
- **12施設・13NPC**：建物をタップすると入口まで移動して解説。村人をタップすると近くまで移動して会話。全NPCに4段階の哲学的で少しユーモラスな掛け合いを追加し、建物にも考察を追加。会話中は画面のどこをタップしても次の台詞に進みます。発見数カウンター。
- **カメラ**：移動中は基本固定。主人公が画面外へ出る場合のみ、最小限の端追従で姿を維持。ドラッグは主人公が画面端に残るところまで、かつマップ外には出せません。移動中はズームボタン／ピンチ／ホイールをすべてロックし、到着後に解除します。自分へ復帰、拡大縮小。マウスホイール操作、PCではWASD／矢印キーも対応。スマホ縦画面を基本に設計。
- **68曲の音楽室**：[hane-san/SRPG-01-FEstyle](https://github.com/hane-san/SRPG-01-FEstyle)（移植当時の旧名：SRPG）の26曲と、追加したオリジナル探索用24曲。四地区別の選曲候補から**入域時にランダム切り替え**（同曲連続を回避）。手動で全68曲から変更することも可能（次に地区を跨ぐまで）。先読みスケジューリングと無音区間のない短いクロスフェードを採用して音切れを軽減。音量調整、BGM ON/OFF、SE ON/OFFを搭載。初期BGM OFF・SE ON。Web Audioでリアルタイム合成され、音声素材の外部配信は不要。
- **楽曲の雰囲気**：勇壮だけれど切ない進軍、懐かしい海辺、温かな港町の寂しさ、雨の石畳、祭りの後の静けさ、星の橋、帰還の凱歌など。
- **独立性**：元の『英雄叙事詩』のリポジトリ、ブランチ、開発設計には変更を加えません。音楽などの元ファイルはコピーを保持します。

## 遊び方

1. 地面または海上の橋をタップ／クリック → そこまで経路を探して徒歩で移動。
2. 施設をタップ → 入口まで歩いて説明。村人をタップ → 近づいて会話。
3. ドラッグで主人公の姿が画面にぎりぎり残る範囲まで見回す。歩行中はカメラ固定（主人公が端まで来たときだけ最小限スクロール）。「⌖ 自分へ」でカメラを主人公の位置へ一度だけ戻す。
4. 「地図」で全島表示。地図や地区名をタップすると、その場所まで徒歩移動。地区に入るたび「♫ 音楽」で選ばれた曲がランダムに替わります（音楽ON時）。手動選曲も可能。BGMをONにするとフィールドで流れます。

※ iPhoneなどのブラウザでは、音を鳴らすため最初の画面タップが必要です（自動再生制限）。

## 構成

独立試遊版：[草原と湖の旅を遊ぶ](https://hane-san.github.io/ARPG-02-retrostyle/?journey=1)。PR #15はmainへ統合済み（`14ea85b3fdceb6a730e1da462816f10d0e96275d`）。112×88の地図に円形草原、大湖、塩原、巨大な石、夕景、少数の暮らしを再構成しています。通常版・台場ミニ版は維持。ローカルは `npm run dev` の後 `http://localhost:4173/?journey=1`。仕様・試遊ルート・検証範囲は [JOURNEY](docs/JOURNEY.md)、最新の受渡しは [CLAUDE-HANDOFF](docs/CLAUDE-HANDOFF.md)。

- `index.html` / `style.css`: UI
- `world.js`: ４地区の地形、橋、施設、NPC、A*経路探索
- `prototype-world.js`: 通常版の座標系を保持した小さな旅の切り出し
- `journey-world.js` / `journey-art.js` / `journey-view.js` / `journey-music.js` / `journey-ui.js` / `journey.css`: 独立した草原と湖の旅、任意の遠望、地域選曲、景色を広く見せる下部メニュー
- `journey-foley.js` / `journey-panorama.js`: 草原湖専用の地面に応じた足音・独立音量、3構図の任意遠望（[追加制作とClaude再監査の引継ぎ](docs/JOURNEY-SENSORY.md)）
- `game.js`: Canvas描画、カメラ、移動、会話、発見、音楽画面
- `sprite-srpg.js`: SRPGのドット絵ユニット描画から移植した主人公
- `music.js`, `audio.js`: 元のSRPGから移植した合成エンジン・26曲
- `extra-music.js`: 12組24曲の新規探索用スコア
- `scenic-biomes.js`: 地区ごとの16景観小エリア
- `tests/`: 経路・音楽データ・景観分布の検証

**範囲外**：戦闘、敵、ストーリー進行、セーブ、屋内マップ、住人の生活AIは未実装。これは探索体験・移動感・音楽・風景の統合を試すプロトタイプです。


## 第2マップ：星風回廊 — STARWIND PASSAGE

中央アジアの地形・旅の記憶をもとにした**架空の淡いファンタジー世界**。現実の地図を再現したものではありません。

- **スタート地点から東へ4マス**の「星風の小橋」をタップすれば、歩いてすぐに第2マップへ移れます。遠くの白磁の未来都にある元の長い星風橋も残しています。向こう側から橋を渡れば戻れます。
- **430×270タイルの広い大地**に、北の草海・水のなくなった海と船の廃墟・石の山道と連続トンネル・農地と水路・チャイハナ・砂漠の青いオアシス都市・険しい渓谷・最北の未来都市を配置。
- イシク・クルをモチーフにした湖は長径約**182タイル**。最大までズームアウトしても、スマホ画面では湖を一望できない大きさです。水には入れませんが北岸・南岸の散歩道へ旅ができます。
- **12施設・12NPC**追加。古い廃港・砂漠都市・山道・大湖などの土地に合わせた短い哲学的な会話があります。
- 各景観に合わせた**新曲18曲**を追加。SRPG＋前回追加した50曲も残し、**全68曲**をメニューから選択可能。地区に入ると自動ランダム選曲（BGMがONのとき）。
- **歩行速度は6.15タイル／秒**。カメラは基本固定のまま、端の追従補間を約7.4/sに上げ、早めに追従を開始して滑らかに。手動ドラッグは感度72%・60fps描画・独立したターゲット補間で、画面のガタつきを軽減。移動中ズームロック、優しい足音は維持。
- AudioContextの先読みを1.25秒へ、BGMの切替を240msクロスフェードに調整。ブラウザの実機音声負荷に左右されるため、完全な無音切れの保証はできません。

### 追加した主なファイル

- `silk-world.js`：第2マップの地形、長大な湖、峡谷、山道、施設、村人、経路探索
- `silk-art.js`：架空の中央アジア景観のパステル調ドット描画
- `silk-music.js`：18曲の新規スコア
- `silk-dialogue.js`：村人と施設の哲学的な会話

### 2026-10-19 カメラと近道の調整

- 開始地点から4マス東に、星風回廊への「星風の小橋」を新設。小さな水路の上に短い木橋がかかり、元の遠方橋と合わせて二つの入路があります。
- カメラ手動ドラッグは入力と描画を分離し、時刻差に基づく指数補間で滑らかにしました。感度は58%→72%。カメラ移動中のみ描画目標60fps、通常歩行は45fps、静止時24fpsです。
- 端追従は6/s→7.4/sに微増、画面端へ来る少し前から滑らかに追従し、主人公が画面から消えない制約は維持します。

## 共同開発運用（SRPG・ARPGと同じ）

採用済み仕様 → Issue → 専用ブランチ → PR → 自動CI（rules / browser） → 人間の判断でmainへマージ → GitHub Pages確認。**現在は初期開発を優先し、main保護の設定は後回し**です。関連する小さな改善はまとめて進め、low/戻せるmediumの独立監査・実機試遊は遊べる区切りにまとめられます。詳しい範囲は[開発手順](docs/DEVELOPMENT.md)。AIは直接mainにpushせず、他ゲームの設計制約を混ぜません。

ローカルのブラウザ検査は `npm install --no-save --package-lock=false playwright@1.57.0` と `npx playwright install chromium` の後に `npm run test:browser`。詳細は [QA](docs/QA.md)。
