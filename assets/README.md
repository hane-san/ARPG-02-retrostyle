# Pastel journey icon
Issue #12: an original 64×64 pixel-art scene of a lone traveller, distant mountains, a large stone monolith and a pale lake at sunset. The artwork is **separate from the Canva-generated concept image** discussed with the producer; this is not a copy or import of Canva output.

- `travel-icon.svg`: editable vector source drawn as hard-edged 64px shapes.
- `travel-icon-32.png`: browser favicon.
- `travel-icon-180.png`: Safari Add to Home Screen icon and header artwork.
- `travel-icon-512.png`: high-resolution art asset for future use only; no PWA manifest is added.

PNG assets use nearest-neighbour pixel scaling and an indexed palette for compact downloads. Keep all variants in sync when revising the artwork. App title, Pages path and localStorage keys are unchanged. These assets are candidate artwork until the producer visually approves the PR on iPhone.
