制作の基準はmain `2c2b98ecf6588bd7c2a9d7d119ef5d03efbbe808`。古いCodex worktreeの未コミット差分は隔離し、mainから別ブランチを作った。最新の入力処理や音声修正を古いファイルで置換していない。

| 意図 | 現在版に対して行うこと |

## 実装の境界

- `journey-foley.js`：新モード専用SE。既存の `createAudio` と同じON/OFF操作に加え、`step(distance,tile)` と音量を持つ。既存 `journey-sound.js` はClaudeのフェード補助として保持し、そこから `gainDuringFade` を再利用する。
- `journey-panorama.js`：480×252のオリジナル3景。地形描画と分離。静的な空と地形は各景2層だけ保持し、描画ごとにCanvas寸法をリセットしない。
- `journey-view.js`：既存の任意開閉・歩行再開・Escapeとフォーカス復帰に、表示中だけ最大10fpsの薄雲・水面更新を追加。既存ゲームの時計を使い、追加の常駐タイマーを作らない。非表示時は更新停止、Reduce Motionでは静止する。
- `game.js`：新モードのSE選択、実距離の供給、遠望への時計、音量UIだけを接続する。`updateMove` の経路・速度・途中変更と、カメラの補間・入力破棄は変更しない。
- `journey-ui.js` / `journey.css`：既存の音楽の窓に足音・操作音の音量を追加。独立した窓や常設メニューは増やさない。

足音は2タイルごと。草・土・石・木橋・塩原の5種類で、短い正弦波と帯域を絞った表面音を変える。170ms以内の操作音はまとめ、音声グループは最大6。ミュートは短くフェードして古い音を停止する。非表示・音量0・音声停止中の距離を捨て、復帰時に足音を溜めて再生しない。音声利用不可やresume失敗でも移動を続ける。

音量は初期55%。追加キーは `tidal-atlas:field-journey-sound-volume`。既存SE ON/OFF `tidal-atlas:field-command-sound` を共有し、BGMと旧モードの音量設定・保存名を移行／削除しない。ゲーム進行の保存は追加しない。

## 検証と再監査の入口

```sh
npm run check
node --check journey-foley.js
node --check journey-panorama.js
npm run test:browser
```

基準mainは53件。専用の8件は距離とフレームレート、5地面、音量保持、連打抑制、ノード解放、非表示・消音復帰、古いWeb Audioの音量補間、古いContextの遅延イベント、音声失敗を検査する。新モジュールはNodeのimportとChromiumの実読み込みでも解析される。最終SHA・実行結果・CIはPRを参照。

ブラウザ検査は既存の通常版の橋往復・台場ミニ・3モードのカメラ入力・Claudeのフェード波形を残す。草原湖を加速やワープなしで一周し、8タイル4足音、独立音量の再訪保持、遠望の表示中だけの更新・Reduce Motion、320×568／390×844／844×390で音量に触れられることを追加確認する。別ページで5地面と2操作音を実合成し、ピーク・DC・隣接サンプル差・始終の無音・終了後ノード解放を検査する。

これらは実装担当の自己確認。過去の [JOURNEY-REVIEW](JOURNEY-REVIEW.md) のPASSを今回の新規SE・遠景の独立監査へ転用しない。Claudeの後続セッションでは、新headを取得して以下を重点確認する。

1. `journey-sound.js` / `music.js` とPR #17の入力修正を保持できているか。
2. #19/#21/#23がその後更新された場合も、最新版同士で合流して足音・窓・44px操作・入口経路を維持できるか。
3. 音量0→復帰、SE OFF→ON、背景化→復帰、音声許可失敗で古い音が再生されないか。
4. 遠望を閉じた後の描画停止、Reduce Motion、長時間の音声ノード／描画キャッシュの有界性。

## 人間の試遊

`npm run dev` → `http://localhost:4173/?journey=1`。出発地で遠望、橋と草原を歩き、音楽の窓で足音を調整。石の峠と夕空の石段でも眺め、閉じて歩行へ戻る。

iPhone Safari実機・WebKit・スピーカー／イヤホンでの心地よさ・実機負荷は未検証。特に「足音が繰り返しても疲れないか」「雲と反射が静かに感じられるか」「音量の窓が歩行を妨げないか」を判断する。公開Pagesへの追加反映は人間のマージ後。Claude自動巡回の設定自体はこのPRで変更・起動しない。
