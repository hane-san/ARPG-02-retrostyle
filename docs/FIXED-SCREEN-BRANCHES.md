# 空の枝道 — 固定画面方式の比較エリア（#112）

2026-11-05採用。基準main `175e59c`（#111）。**固定画面方式を比較する独立した実験エリアであり、全体への採用は未決定**。既存の33地域・87地点・32人・110曲、標準のシームレス探索と旧モードを残す。戦闘・敵・クエスト・物語の確定・セーブは追加しない。

## 資料とコードの照合

- #104/#105はシームレスの追従比較で、固定画面遷移を持っていなかった。QAの#104冒頭には#108で変更済みの標準カメラの古い説明が残っていたため訂正。今回の固定画面を、その既存デッドゾーンと同一視しない。
- `index.html` の旧音楽室の固定文は68曲のみと書いていたが、実ライブラリは110曲。説明を訂正し、譜面・イベント・番号は全110曲とも変更しない。
- DESIGN冒頭の2世界はclassicの索引。現行の標準は同資料後半の480×832の巡礼で、ここに固定画面を機械的に割り当てる変更はしない。

## 技術計画と境界

`fixed-screens.js` が8画面の地形・接続・入力受付と移動状態を持つ。各画面は **15×15タイル、32px/タイル**。寸法対応の既存 `silkPath` と `routeJourneyWalk` を使い、経路は画面内だけで探索する。内部の目的地へ向かう経路が出口を近道に使わないよう、出口を明示した目的地にした時だけ通す。水・崖・家・幹は通れず、橋と階段は実在する床である。

`fixed-screen-art.js` は既存westernの床・家、landscapeの糸杉・根と葉、skyの雲と光を使う。可歩地形と背景は別レイヤー。高庭の同じ青屋根と煙突を、集落・坂・風道・帰路から距離・方角・木立の遮蔽を変えて描く。北への接続は歩行盤上端の岩陰へ抜ける階段とし、道が開いた空で突然切れて見えることを避けた。

`fixed-screen-view.js` は独立Canvas、入力、地図、音の距離を持つ。既存世界はオブジェクトごと保持して休止し、再生成・再配置しない。新しい画面番号や座標の常設HUDはない。8画面の地名と既存の四操作を使う。独立Canvasは未使用・復帰後に1×1へ縮め、既存世界のチャンク上限42を変えない。

この比較領域だけ、地図・音楽・手引き・会話の表示中は移動と遷移を休止する。通常世界のメニュー中歩行は変更しない。#98の未決定P1を全世界へ採用した変更ではない。

## 倍率と画面遷移

実際の `stage` を幅W・高さHとして、全画面共通の等方倍率を `min(0.9, (W−24)/480, (H−24)/576)` とする。盤の左右は中央寄せ、下辺はUIの上18px。最低限の空の余白を含めて計算し、縦画面では上方に大きな空と遠方の景観を残す。タイル・人物の縦横別の引き伸ばしはない。

画面内を歩いても構図と倍率は変えない。幅の違う画面への回転・実描画領域の変更時だけ、全画面共通の寸法へ再計算する。画面別の特別な引きは今回は採用せず、比較の論点として保留。小さい縦画面の人物は約20px、390縦は約24px、430縦は約27pxを目安とし、実測値はPR／ブラウザJSONへ記録する。

横画面は一画面を収めるため小さくなり、空と谷が左右へ広がる。縦を主とした比較であり、横だけ別倍率へ拡大して盤を切らない。実機のセーフエリア・アドレスバーで実描画領域が変われば同じ式で再計算する。

端の3マスの接続から **280msのsmoothstepスライド**。暗転・ズーム・オーバーシュートはない。Reduced Motionは即時切替。到着は対応する端から1マス内側で、経路と到着予約を消す。入力の世代を変え、遷移中のタップや押しっぱなしのキーが到着後の移動へ流れないようにする。確認ダイアログは挟まない。回転が遷移に重なった時は安全な到着先へ一度だけ確定し、新しい画角へ合わせる。

## 入り方・戻り方・音

1. 船着場の試遊道標、またはランダム試遊の到着案内で **「空の枝道へ（画面切替）」**。手引きにも同じ入口を置く。
2. 道をタップ、または矢印キー/WASDで歩く。地図の隣の地名を選ぶと、その出口まで徒歩で進む。地図は未知の全経路を自動で解いて飛ばさない。
3. 入口の「帰りの道標」をタップして着くか、手引きの **「元の場所へ戻る」**。全画面・歩行中・遷移中から帰還できる。

入場前のマップ、最後に確定した合法な床、カメラの位置・倍率、選曲・静けさを保持する。通常のカメラと選曲のディレクタは交換せず休止するので、候補や追従の設定を別方式で上書きしない。帰還時は古い経路・到着予約・指を破棄し、同じ安全な床と通常の構図へ戻す。入場中に回転した場合は現在の表示領域の安全制限を適用する。世界や進行を保存する新しいlocalStorageキーは追加しない。

BGMは景観の元と同じ **47:2** を全8画面で継続。画面切替では再生やsetSceneを呼ばない。音楽室の手動選曲も画面間で保つ。復帰時は入場前の曲へ戻し、BGM/SEのON/OFFと独立音量はユーザーが変更した現在の値を保つ。新曲は追加しない。既存の足音と距離ディレクタ、水辺の小さなdripを使用する。旧世界の環境音は休止し、混ざって残らないようにする。
