# 旅先の人々（#150）

採用：短く読みやすく、読んで楽しい会話と住民の増員。画面切替アトラスの既存20人を個別に書き直し、24人を追加する。各会話は短い2文。食べ物、仕事の小さな失敗、土地で見つけたものなど、人ごとの用事を話す。世界の成り立ちを確定せず、静かな原っぱや閉殿は残す。

実装前設計：`fixed-people.js`へ台詞と配置条件を集約する。既存人物の位置と見た目は維持。追加人物は地形と小物の生成後、実際の草地から決定的に選び、出口・木・設備・調べ口・小物・他人物を避ける。床・水・固体・小地形を変更しない。既存のタップ会話と描画を使い、新しい保存状態・クエスト・会話進行を追加しない。連続世界と旧モードは変更しない。

全員の床・隣接会話位置への到達性、会話の短さと重複、静かな区間、地形不変を検査する。320/390縦で既存・追加人物へ通常タップで会い、会話を閉じて旅へ戻り、復路でも再会する。必須CI後に既存方針のauto-mergeと公開確認まで行う。実機iPhone・実耳・独立監査・人間の文章受入は未確認。
