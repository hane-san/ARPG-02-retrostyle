# 小さな旅（台場ミニプロトタイプ）

## 位置づけ
- 企画上の採用：2026-10-19、広い本編に進む前に、まず小規模な完成形を作る。
- 実装：Issue #6 / `feat/6-compact-journey` 作業ブランチ。PR・レビュー・iPhone試遊を経るまでmainの採用済みリリースとは区別する。
- このモードは **通常版の世界を置き換えない試遊モード**。通常版 `./`、試遊版 `./?prototype=1`。ヘルプ画面から切替可能。

## 小さな旅の仕様
- 潮環群島の左側80×110論理マスのみを利用し、元の絶対座標を保持。森林地区「風環の庭」と旧港地区「潮騒の旧港」のみ。
- 開始点は元の(41,40)。森林と港は「北の縦断橋」で接続。
- 訪問対象4施設：風車の祈り、森の渡り社、海門城と水門、潮見バザール。登場NPC4人。
- 地面タップ、自動経路探索、NPCと施設、地図・音楽室・カメラ・ズームは元の実装を使う。
- 4施設訪問で短い達成メッセージを表示するが、強制終了も一本道クエストもない。自由に歩き続けられる。
- ミニモードは星風回廊へ渡れない。大陸および通常版の2本の橋は元コードのまま残す。
- 戦闘、アイテム、経験値、セーブ・クエスト進行は追加しない。

## 技術と不変条件
- `prototype-world.js` は既存 `makeWorld()` のタイルを切り出し、4施設と4NPCをフィルタする。切り出された施設の衝突判定は解除し、見えない障害物を残さない。
- `world.js` 内の `findPath` は元の164×120の線形インデックスを使う。小世界のX/Y座標を動かさず、範囲外の `walkable` をfalseにすれば安全に再利用できる。**原本座標系依存のため独立監査で要確認**。
- 原本 `world.js`、`silk-world.js`、通行ルール、68曲、保存キー `tidal-atlas:`、通常版の表示タイトル、配信URLは変更しない。
- 体験評価は「目的地指定なしに歩きたくなるか」「森と港が別の土地に感じられるか」「移動・カメラ・会話が自然か」を中心にする。

## 試験と人間の受入
1. `npm run check`：既存Nodeテスト＋`tests/prototype.test.mjs`の可達性、オブジェクト数、不変条件を検証。
2. `npm run test:browser`：通常版の2世界移動と、モバイル幅でのミニ版読み込み、地図2地区、森→旧港の移動を検査。PRの `rules` と `browser` を参照する。
3. 別担当の独立監査：到達可能性、crop外アクセス、未選択施設当たり判定、標準版に対する回帰、セーブ/設定の共有を確認する。
4. プロデューサーさんのiPhone Safari試遊：通常版とミニ版の行き来、歩行中のピンチズーム禁止、長い徒歩指定、森→港の変化、NPC・施設、BGM/足音を実機で確認する。
5. 未実施の試験や独立監査はPASS扱いしない。mainマージは本人の最終判断に委ねる。
