# 潮環群島 × 星風回廊 — 旅と世界の方向性

更新：2026-10-23。採用根拠はGitHubのIssueと最新main。未共有のチャットを補完しない。

## 採用済みの体験

- 架空の中央アジアに着想する幻想世界を、無口な旅人が自由に歩く2D探索。
  戦闘・強制クエスト・セーブゲーム・課金は入れない。人物の感情解釈は遊ぶ人へ委ねる。
- 大きな湖と草原、塩原、街、峡谷、高地、旧水底、南西遺跡をつなぐ。
  巨大湖の水は歩けず、岸や橋を選んで旅する。既定入口と旧モードを維持する。
- [#51](https://github.com/hane-san/ARPG-02-retrostyle/issues/51)：
  日常の用事、冗談、変な趣味、小さな寂しさ、局所的な怖さを混ぜる。
  全員に哲学を語らせず、短い任意会話・小物・場所ごとの音で寄り道を生む。
  MOTHER的な日常の変さは参照しても、固有の人物・文章・旋律・素材は複製しない。
- 茶屋・港を一様にホラー化しない。不可解な低音は黒石周辺へ、空の涯には静けさも残す。
  先行追加の美術小物や住人は削除せず、元の設定・説明を保つ。
- [#53](https://github.com/hane-san/ARPG-02-retrostyle/issues/53)：地形・景観PRの
  統合後にNPC・小物・音源・遠望の配置を点検する。配置の救済で水を陸に変えない。

## 今回の試作と確認の境界

小物12点、既存NPC12人への短い生活文、13か所の近接音を追加する。
設計・座標・検証は [小物・音の試作](journey-curios-51.md) を参照。
原曲68曲と地域選曲、BGM既定OFF・SE既定ON、5段階自動画角、手動ズームなし、
`tidal-atlas:`、外部CDN・音源なしを維持する。先行PRの追加曲も削除しない。
CIやChromiumでの合成検査は、実耳・iPhone・面白さの確認と区別する。
