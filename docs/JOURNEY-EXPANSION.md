# 景観・音楽・画角の実験：広がった旅の世界

2026-10-21／Issue #39／**企画の実験、設定は未採用**

## 変えたもの
- 既定の旅マップを**112×88（9,856マス）から176×136（23,936マス）**へ拡張。広さは約2.43倍。
- 元の草原・巨大湖・港・22施設・16人・9遠景の座標は維持。東と南東の陸続きの新領域に7景観地域、13探索地点、11NPC、7遠景。
- 景観：暖色の赤峡谷／遠くを見通す雲上高地／道が途切れる『空の涯』（空を主役にした固有の超遠景、北東の小さな石の腰掛けで任意に表示）／舟と道が入れ替わる河畔／近寄って見る玻璃の街／雨の季節の湿原／白い旧水底と隊商。
- 自然の小さな川と岩の崖は歩行不可。北東・南東から歩ける通行可能な橋と水路の渡りを追加。従来の大湖は干上がらない（年代変化未実装）。
- 5段階ズーム **1.8／1.35／1／0.8／0.6** の種類は変えず、土地の性質に沿って自動割当。温室街は近く、山と旧水底は遠景重視。玻璃回廊の入口では最も近い1.8倍を試せる。画角確定は既存の滞在判定を使う。
- 68曲はそのまま、14地域ごとに異なる曲のプールを設定。再生の切替判定は2.2秒滞在・12秒保持のまま。

## 景色の評価
1. パレットの違いが強すぎず、土地を歩く気持ちが変わるか。
2. .6倍の遠景でも主人公や道が分かるか。1.35〜1.8倍で建築が読めるか。
3. 画角が切り替わるときの違和感・停滞・戻りはないか。
4. 音楽は地域の印象を変えるか。切替時のポップノイズ、待たされ感、似ている曲が多すぎないか。
5. 小川や断崖、二つの橋により、探索経路が増えているか。
6. 以前の旅を懐かしむ台詞と、新しい土地の生活・信仰が釣り合っているか。
