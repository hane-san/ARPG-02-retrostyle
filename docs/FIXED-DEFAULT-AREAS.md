# 画面切替を既定に：エリア音楽・背景レイヤー・遊び心のある地形（2026-11-12）

## 制作者の指示（チャット、2026-11-12）

> rétrostyleは、スマホ縦画面を前提にしつつ、レイヤーとして、基本的にはマップ上のオブジェクトがあってその後ろに背景があるのがベースということ（もちろん場所次第！自然さ優先！）、全マップで音楽が違うというよりはエリアごとにわかれる感じとかにしたいな！ただいまの曲どれもすごく良いのでうまく再配置してあまり減らさないのと、サウンドルームでは全て聴けるように。地形とかももう少しゼルダみたいに様々な遊び心があるといいな。あとデフォルトを追加した画面切り替えのやつにしたいな

#112〜#124 の「全体方式の採否は未決定」は、この指示で**画面切替を既定に採用**へ置き換える。

## 1. 既定の入口

| URL | 開く世界 |
|---|---|
| `./` | 100枚の画面切替の旅（中央の旅支度の分水庭から） |
| `./?walk=1` | つながった一枚の巡礼（以前の既定。船着場から） |
| `?journey=1`・`?atlas=previous`・`?maze=turns`・`?camera=directional|deadzone` | 以前どおり、つながった世界の各比較 |
| `?mode=classic`・`?journey=0`・`?prototype=1` | 以前どおり |

- 起動時は通常の巡礼を船着場に用意してから画面切替へ入る（`if(FIXED_DEFAULT)enterFixed()`）。手引きの「つながった大地を歩く（以前の旅）」と、分水庭・旧集落の道標で巡礼へ移り、手引きの「空の枝道へ（画面切替）」で戻れる。
- 画面切替中の手引きは画面切替の説明を先頭にし、つながった世界の説明は隠す。巡礼へ移ると元に戻る。
- 保存キー `tidal-atlas:`・曲の設定・BGM OFF／効果音 ON の既定は変えない。位置は保存しない（再読込で中央から）。

## 2. エリアごとの音楽

`fixed-areas.js` の20エリア（10×10の盤面を、隣り合う2〜8枚ずつに分けた連続領域）。

- 同じエリアの盤面を行き来しても曲は変わらない。エリアの境を越えたときだけ、次の盤面のスライドに合わせて短いクロスフェードで切り替える（以前の仕組みを流用）。
- 各エリアは4〜7曲のプレイリストを持つ。最初は代表曲。そのエリアで実際にBGMを聴いて「2ループ、かつ150秒以上」たつと、次の曲へ通常のゆるやかなクロスフェードで移る。スライド中・静寂の殿・一時停止中・BGM OFFでは進まない。位置はこのページを開いているあいだだけ。
- 全110曲（55譜面×2面）をいずれかのエリアに配置した（重複は柳と点描の水辺の4曲だけ）。現行メインの全33地域の代表曲も、すべてどこかのエリアで流れる。サウンドルームの一覧（110曲）はそのまま。
- 扉のない受水殿（`sealed-court`）は従来どおり静まる。

## 3. 背景レイヤー（縦画面前提）

`fixed-backdrop.js`。前から順に：

1. **盤面のオブジェクト**（建物・木・人・主人公・新しい小地形）— 足もと順に重ねる。
2. **歩ける地面**（従来のタイル）。
3. **周囲**：盤面のうち歩けない空白セルを、その土地の自然な周り（森＝樹冠、草原＝丈の高い草、段畑＝畝、集落＝庭、海岸＝海、湿地＝水と葦、尾根＝岩屑と雪、塩原・乾いた土地、石の都＝敷石と柱）で埋める。盤面ごとに静的な層として最大14枚を保持。
4. **隣の盤面**：薄いもや（0.34→0.24）で、つながる土地として。
5. **遠景**：空の下に、土地に応じた遠い山・海・森・畑・家並み・柱列を、明るさを変えた3層で。縦画面の上部が空だけにならない。
6. **空**：#122の11の空の色・北端の空はそのまま。

場所次第の例外：断層、尾根、北端の上3段では、以前どおり崖の面と空が見える。

## 4. 遊び心のある地形

`fixed-features.js` / `fixed-feature-art.js`。旧8画面・中央の分水庭・斜めの断層の2枚・静かな殿を除く88枚に、盤面ごとの種から数個ずつ置く。

- 茂み・岩・積み石・切り株（実際に通れない）を2〜3個のL字に置き、内側に**小さな発見**（光る点）を隠す。踏むと一文の描写が出る。アイテム・数え上げ・保存はない。
- 水辺の盤面に**飛び石**（1〜2マスの流れを渡る近道、新タイル `k`）。
- 草地の**小さな池**、**道しるべ**（触ると隣の土地の名前を方角つきで読む）、花壇・石の輪・睡蓮・葦（地面の飾り）。
- 置くのは外周2列より内側で、各出口のレーンの端から4マス・建物や設備の範囲と周り1マス・入口・人のまわりを避けた場所だけ。茂みなどの固い小地形は専用のマス `o`（建物の足もと `h` と区別）。置くたびに、全床・全レーン・建物の入口・人が一続きで届くかを検査し、切れるなら置かない。

## 6. 見栄えの総点検（2026-11-13、制作者の指示）

> 画面の端の見せ方とか、地名表示が没入感を削いでいたり、高い建物の上部分がフェードしていて不自然とか、遠景に背景グラ重ねるのが一部見え方不自然とか、そういうの徹底的にチェックして、見栄えの良さやデザイン性的なところを重点的に整えて欲しい

全100枚を縦390×753で撮影して点検し、次のように直した。

- **高い建物**：歩ける盤面（スライド中は前後の2枚）を、隣の盤面より手前の層に描く。隣の盤面にかかる遠景の霞は、手前の盤面に届かない。列石の塔・風車・帝門・閉殿・空樋は、盤面より上の部分まで欠けずに見える。
- **スライド**：到着する盤面と離れる盤面は、背後の層（霞あり）と手前の層（霞なし）の両方に、スライドの進み具合を重みにして描く。始まりと終わりの見た目が飛ばない。
- **地名の札**：出口の「〜へ」と「帰りの道標」の札は、常には出さない。着いた直後（約2秒、その後0.9秒で消える）、その出口や道標から約3.6マス以内に近づいたとき、そこへ向かって歩いているときだけ浮かぶ。枠線のない、柔らかな影つきの札に変えた。出口の石の矢印は小さく、普段は薄くした。Reduced Motionでは消えるときのフェードはない。タップできる範囲は以前と同じ。
- **遠景**：遠い家並み・柱列・台地・帝都の外郭は、中景の丘の後ろに立つ（足もとが中景に隠れる）。空中に浮いて見えない。帯のような畑の線はやめ、生け垣の点に変えた。
- **画面の端**：遠景と盤面のあいだの平らな色の帯をやめた。その土地の周りの模様（敷石・草・海・樹冠など）が、柔らかくにじみながら画面の端まで続く。隣の盤面の霞は空の色に合わせ、上と横の消え方を長くした。

## 7. 移動・会話・当たり判定のUI見直し（2026-11-13、制作者の指示）

> 隣のマスへの移動がらみとか、あと会話とか、障害物の当たり判定とか含めたUIの見直し（隣の横のマスのが1枚だけ見えてると枠みたいで不自然とか）

- **端の細い隣の盤面**：縦画面で左右や下に2マス分より細くしか見えない隣の盤面は描かない。その場所には土地の周りの模様が続く。出口の道は、盤面の外へ少し伸びて消えていく。横画面のように広く見える場合は、これまでどおり隣の土地を描く。
- **歩けない周りの見分け**：周りと歩ける地面の境目に、土地ごとの障害物の縁を描く（集落＝生け垣、草地＝茂み、段畑＝柵、石の都＝低い胸壁、塩原・乾いた岩・尾根＝石の列、海＝白波、湿地＝葦、森＝樹冠）。床に似た周り（草・庭・敷石・塩原・乾いた岩）は少し暗くした。見えない壁はなくなった。当たり判定の配置そのもの（建物・木・小地形の固いマス）は変えていない。点検で、見た目との大きなずれはなかった。
- **歩けない所のタップ**：茂み・岩・木・建物・周りの土地を盤面の内側でタップすると、その横のいちばん近い歩ける場所まで歩く。水面と外周の端のマスは、これまでどおり何もしない（水は当たり判定の面のまま、端は出口の近道にならない）。
- **会話**：画面切替の旅では、会話の札を主人公のすぐ上に出し、しっぽで主人公を指す。上に場所がなければ下に出す。話し手の肩書きは、いまいるエリア名にした（以前は「空の枝道の暮らし」）。
- **画面の移動**：スライド中も主人公が歩く動き（小さな上下）を続ける。
- **呼び名**：画面切替の呼び名を「空の枝道」から「画面切替の旅」に揃えた（地図の題・手引きのボタン・読み上げ名）。

## 8. 出口の地名の札をなくす（2026-11-13、制作者の指示）

> いっそのこと矢印の地名表記なくしちゃおうかな？どこから移動できるかさえわかればそれも没入感的にありかも

- **出口の札**：盤面の上に出口の「〜へ」の札は出さない。着いた直後も、出口のそばでも出ない（6節の「浮かぶ札」を置き換える）。隣の土地の名前は、地図（地図ボタン）でこれまでどおり読める。
- **矢印**：出口の目印は、地面の石の二重矢印だけ。少し大きく（1.2倍）、普段の濃さを上げた（0.62→0.74）。着いた直後、そばに来たとき、そこへ向かって歩いているときは、これまでどおりはっきりする。
- **タップ**：見えない札の場所をタップしても出口へは向かわない（見えているものだけが反応する）。描いた矢印は、角にある2本目の帯の矢印も含めて、すべてその出口のタップ先になる（以前は、白い花の道の東、ケルンの曲がり角の西の2本目の矢印が、南の出口に取られる、または反応しなかった）。出口の縁と道の続きのタップは変えていない。
- **帰りの道標**：菱形だけでは何をするものか分からないため、その札（着いた直後とそばに来たときだけ）は残した。

## 9. ゼルダのように自然な地面・縁・つながり、エリア名（2026-11-13、制作者の指示）

> 地形や建物やオブジェほか含め、細かな見栄えやマップの繋がり方とかをできるだけゼルダっぽく自然に and UIとか洗練させて

- **歩ける地面**：歩ける地面は、淡い四角の敷物（以前の巡礼のタイル＋空の色の薄い膜）ではなく、その土地そのものの地面として描く。種類は芝・森の土・砂・砂利・雪・塩の地面・敷石で、色は周りの土地と同じ系統。マス目に沿わない柔らかなむらと、小さな草・花・落ち葉・小石を散らす（`groundLayer`、盤面ごとにキャッシュ）。階段・橋・水・建物の足もと・水路は、これまでの絵のまま。
- **道**：道のマスは一本続きの道として描く。道が続かない角は丸め、縁を少し暗くして踏み固めた感じを出す。階段・橋・盤面の端では角を丸めず、そのまま次の画面へ続く。
- **茂みの縁**：草地と庭の周りでは、歩ける地面に面した周りのマスに、丸い茂みが連なる壁を描く。地面の上に少しはみ出し、マス目の段差が生きた縁に見える。森は木の冠が同じように縁を作る。茂みの奥には、ところどころに丸い木。当たり判定は変えていない（茂みは以前から歩けない周りのマス）。
- **崖**：尾根などで本当に地面が落ちる所の崖は、平らな灰色の箱ではなく、明るい縁・岩の筋・暗い足もと・ぎざぎざの下端を持つ岩肌にした。
- **盤面のつながり**：盤面の境では、両側の盤面が「両方の地面の中間色」と「両方の道の中間色」へ、3マスかけてなめらかに近づく。境をまたいでも地面と道の色が途切れない（以前はそれぞれの土地の基調色の平均を、マスごとに段のついた濃さで塗っていた）。
- **木**：出口の矢印の近くにあるだけの木は、もう半透明にしない。半透明になるのは、冠が本当に矢印を覆う木だけ。主人公が木の後ろにいるときに薄くする処理は、これまでどおり。
- **エリア名**：音楽のエリアが変わったとき（盤面が変わるたびではない）と旅を始めたときだけ、エリア名が空の上にふわっと浮かび、約2.6秒で消える。枠はなく、操作は妨げない。縦画面では空の上に出る。低い横画面では、盤面の上端を一瞬かすめる。Reduced Motionでは動かさず、短いフェードだけにする。
