## 指摘と修正確認

1. 遠望を閉じた瞬間は入口ボタンがhiddenのままで、focus復帰できなかった。入口の表示を同期してからfocusするよう修正し、×とEscapeで再確認。
2. 既に隣にいるNPCの会話がpointerupで開き、同じジェスチャのclickで即時に閉じた。Canvasの表示直後のclickだけ除外し、通常の外側クリックと道具操作は通すよう修正。隣接再会話と表示直後の音楽切替で再確認。
3. 下部へ移した遠望入口に旧 `.dock button` の濃紺の色が勝った。旅モード専用CSSの優先度を明示し、計算済みスタイルと実画面で再確認。
4. 操作できる下部道具と窓の `aria-modal=true` が不整合だった。新モードだけfalseへ変更し、窓の開閉時フォーカスも再確認。
