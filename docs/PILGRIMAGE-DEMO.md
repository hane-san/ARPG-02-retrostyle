# 巡礼と露出遺構：既定旅マップの高密度試遊実験

作成：2026-10-21／Issue #32／**案の視覚化であり正史採用ではない**。

## 今回試す感情
1. 幼年期：帰る港と船、仲間と寄り道できる身近な世界。大人が守る境界。
2. 長い旅の始まり：水が退き船便が途切れる、川や陸路に沿って未知の世界へ。
3. 帰路：かつての島が陸続きになり、細い塔の下に巨大な幾何学構造が露出。廃墟だけでなく、新しい暮らし・信仰・商売がある。

時間経過・水位シミュレーション・船舶移動・巡礼クエストは**今回実装していない**。地点説明と遠景で、時間層の手触りを試す。具体的な時系列や古代人の思想・制度の真相は保留。

## 現在の既定マップに加えるもの
- 既存112×88・6施設・4NPC・3任意遠望を維持し、**+16発見地点、+12 NPC、+6遠望**。
- 港：巡礼船の甲板、炊事係と昔の仲間。
- 草原：子供道の門、止めていた大人の見張り台、水位標、鈴の石畳、星図、連環の基標。
- 水際：露出回廊、旧船階段、移住者の苗床、旧船員の菓子屋と夕市。
- 塩原：同心円祭壇、新しい門前町、塩採りの共同井戸、巨大な白い壁、天秤の門。
- 六つの観景：泊まる船／大人に止められた門／幾何学祭壇／新集落／途方もない壁／干上がった航路。
- 新設の小物は**非閉塞の試作レリーフ**。衝突を持つ巨大構造物や湖の地形変化は先送り。
