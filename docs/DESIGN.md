# 設計索引：潮環群島 × 星風回廊

## 企画と現在実装

- 2D Canvasドット絵の徒歩探索ゲーム。2つの独立した地形マップを橋で往復する。敵、攻撃、クエスト、セーブゲームは未実装。
- 第1世界「潮環群島」：164×120マス。森の風環、白磁の未来都、潮騒の旧港、蒼光の新港の4地区。16景観パッチ、12施設、13住人。開始点は (41,40)。
- 第2世界「星風回廊」：430×270マス。**現実の中央アジアではなく架空の幻想世界**。湖（イシク・クルの巨大さを着想元）、露岩の峠・石門群、オアシス都市、農地と水路、チャイハナ、渓谷、干上がった海の船、北の草原と未来都市。9曲地域、12施設、12住人。
- 両世界の橋：潮環の開始点の東約4マス (45,40)、未来都の大橋 (160,38) から星風回廊 (28,146) へ。星風回廊 (13,146) から潮環 (156,38) へ戻る。

## アプリ構造

`index.html` → `game.js` (UI / pointer / キー / Canvas loop)
→ `world.js` / `silk-world.js` (静的地形 / A* / 世界遷移データ)
→ `camera-limits.js` / `journey-camera.js` (bounds / easing / 屋外固定・例外的な自動画角)
→ `pilgrimage-world.js` / `pilgrimage-art.js`（現行巡礼の地形・衝突・景観）
→ `journey-world.js` / `journey-expansion.js` (既定旅地形・拡張ルートと地点)
→ `silk-art.js` / `scenic-biomes.js` / `sprite-srpg.js` / `journey-expansion-art.js` / `journey-expansion-vistas.js` (描画)
→ `dialogue-data.js` / `silk-dialogue.js` (会話)
→ `music.js` / `extra-music.js` / `silk-music.js` / `zone-music.js` / `audio.js` (Web Audio)。

HTML, JSはES modulesでroot配信。ゲームのソースが正本で `dist/` は使わない。

## 小さな旅（main統合済みの任意モード）

以前の広い世界 `./?mode=classic` の2世界は維持する。`./?prototype=1` のみ `prototype-world.js` で80×110を切り出し、森と旧港の2地区・4施設・4NPC・北の縦断橋を使う。星風回廊への遷移はない。経路探索では元の164幅の絶対座標を保持し、切り出し範囲外を歩行不可にし、非選択施設の見えない当たり判定を残さない。
詳細仕様、受入条件とPR #7の統合後レビュー依頼は[PROTOTYPE](PROTOTYPE.md)。ミニ版を既定入口へ切り替える案は未採用。

## 画面固定感とシームレス徒歩の比較試作（Issue #104）

2026-11-03の制作者の承認により、初期ゼルダのような構図の落ち着きと、MOTHER/ポケモン系の連続した長距離徒歩を両立する**デッドゾーン型のカメラA/B試作**を追加した。

- #108の標準 `/`：下記の構図を保つ#105追従。以前の#96/#101は`?camera=directional`に保持。
- 標準（互換URL `/?camera=deadzone`）：現在の巡礼マップだけ、画面中央付近のデッドゾーン内では視点を静止させる。そこから長く進むと、方向・画面の縦横比に応じて滑らかに前方の余白を作る。屋外/高地/帝都の倍率・地名・音楽・経路・徒歩速度はどちらも同じ。
- 手引きからA/Bリンクへ進める。**切替はページ再読込**で、まだセーブゲームはないため移動中の現在地を引き継がない。旅の常設操作ボタンを増やさない。
- 街道や村の「一枚絵の落ち着き」をカメラで比較する試作であって、ゼルダ式の固定部屋や画面切替は**実装していない**。まだない屋内マップやシナリオ構造も追加しない。人間のiPhone Safari試遊で比較し、正式なデフォルト変更は#108の制作者指示で採用された。現在の比較URLは下記参照。

## 操作と基本不変条件

既定の草原湖 `./` と `?journey=1` は、Issue #80で採用された **約10分の巡礼一周→変貌する後半→巨大拠点** の試作。`pilgrimage-world.js` の480×832マス、33地域、86調査地点、NPC32人と既存の任意遠望・道端の造形で構成する。淡い色と地域別の素材/音、実際の柱・門・桟橋の足元の衝突を使い、庭の床や柱間を歩ける。推奨順路43区間は2,485マスで、観察を仮に190秒加えた設計目安は現地徒歩約10.5分/地図徒歩約8.8分。人間の所要時間や怖さの受入は未検証。

[実装前の計画・測定・試遊](PILGRIMAGE-LOOP.md)を参照。ボス戦/クエスト/セーブ/帰路のシナリオはない。通常屋外0.8と作者指定の大遠景0.46/0.38（Reduced Motionは0.6）、全106曲のうち原曲68曲と全追加曲、独立音設定を保つ。

以前のatlasは `?atlas=previous`、その迷路Bは `?maze=turns`。歴史的な初期草原湖は [JOURNEY](JOURNEY.md)、巡礼断章は [PILGRIMAGE-DEMO](PILGRIMAGE-DEMO.md)、先行拡張は [JOURNEY-EXPANSION](JOURNEY-EXPANSION.md)、帝都の比較試作は [IMPERIAL-WATERWAYS](IMPERIAL-WATERWAYS.md) に残す。旧atlasの座標固定/全NPC維持はその版の契約であり、制作者が許可した今回の新配置には適用しない。旧2世界/classicとミニ/prototypeは維持する。

**Issue #96（2026-11-02）の試作**：現行巡礼で長いタップ移動を行うとき、先読み追従の量を固定3マスから画面の幅・高さに応じた比率へ変更。縦持ちの左右移動は主人公が進行方向と逆側の約20〜25%に落ち着く構図を目標とし、上下移動はやや控えめ（上行きは画面下寄り、下行きは画面上寄り）。横持ちでは左右の偏りを弱める。2マス程度の短いタップと前方手動パン後の追いつき待ちは従来通り。通常屋外0.8、地域の特別遠景0.46/0.38、Reduced Motion、地図/現地移動の経路と速度は不変。iPhone実機の好みは試作PR統合後に確認。

- 32px論理マス、マス目自体は非表示。目的地タップでA*徒歩、遠方は地図パネル。NPC/施設タップで到着後会話・説明。画面タップで会話進行。
- 移動速度は6.15タイル/秒（旅モードでは短距離・広域移動に別速度を使用）。小さな足音。旧2世界・台場ミニは端で穏やかに追従。既定旅モードではIssue #58の経路先読み自動構図（短距離タップ／広域地図の両方）、移動中のドラッグ無効・行先タップ有効を維持。**Issue #70の試用仕様**：従来のIssue #62の地域別6倍率切替は、試遊で視界が頻繁に変わる疲れを感じたため変更。既定旅モードの屋外は、港・都市・茶屋・草原・湖・高地・遺跡・一般の景観演出を含め**常時0.8倍**を標準とする。特別に指定された `journey-scenic-wide` の展望地点だけ0.6倍へゆっくり移行し、通過後0.8倍へ戻す。**実在する屋内に限る1.35倍**の枠は維持するが、旅モードにはまだ屋内マップが存在せず、茶屋・モノリス・ガラス回廊へ近づいただけで室内扱いしない。かつての1.0／1.15／1.8倍の屋外近景は今回停止。屋外の地理・地域名が変わっても倍率は変えない。手動ズーム禁止・既存の前方追従/滑らかな補間・主人公可視/境界制限は不変。停止中の手動パンは旅モードのみ感度0.95／補間11.5で機敏かつ滑らかに動かす（旧モードは0.72／9.5）。手動倍率変更は廃止済みのままとする。
- 地形・湖・構造物は通行不可（各入口は歩行可）。湖はどの拡大縮小でもスマホ1画面に収まらない大きさ。
- 原曲34組×2=68曲と追加38曲の計106曲。新エリア入域で地域別選曲、初期BGM OFF・SE ON。音切れ対策として先読みと短いクロスフェード、Web Audio操作解禁あり。
- 基本はスマホ縦画面。レイアウトがゲーム座標を予期せずずらさないこと。

## #108：標準の構図と地続きの南東

`useComposedCamera`が現行巡礼の既定を選ぶ。`./`／`?camera=deadzone`は#105、`?camera=directional`は#96/#101。手引きから再読込で比較し、常設HUDは増やさない。旧版には適用しない。

`landscape-geometry.js`の広い連続場が土地の輪郭と表面を作り、`landscape-objects.js`が群落・幹・岩・花を配置する。固体自然物は道／水／建物／NPCから離れた広い床だけに置く。幹は主人公より先、樹冠は後に描き、人物が隠れる時に薄くする。全オブジェを毎回描かず可視範囲で絞る。

`southeast-world.js`が地域29〜32の実地形、10地点、6人、両岸の回遊路を定義し、`southeast-art.js`が川岸・層状岩・海食アーチ・食堂・水車を描く。石橋の先の岩島も実在する床。`southeast-music.js`の4曲は51:1〜52:2へ追加。通常屋外.8、台地と海岸は明示した地域全体の.6で、物体に近づくたびの拡縮は行わない。[台帳](LIVING-LANDSCAPES.md)。
