# 設計索引：潮環群島 × 星風回廊

## 企画と現在実装

- 2D Canvasドット絵の徒歩探索ゲーム。2つの独立した地形マップを橋で往復する。敵、攻撃、クエスト、セーブゲームは未実装。
- 第1世界「潮環群島」：164×120マス。森の風環、白磁の未来都、潮騒の旧港、蒼光の新港の4地区。16景観パッチ、12施設、13住人。開始点は (41,40)。
- 第2世界「星風回廊」：430×270マス。**現実の中央アジアではなく架空の幻想世界**。湖（イシク・クルの巨大さを着想元）、露岩の峠・石門群、オアシス都市、農地と水路、チャイハナ、渓谷、干上がった海の船、北の草原と未来都市。9曲地域、12施設、12住人。
- 両世界の橋：潮環の開始点の東約4マス (45,40)、未来都の大橋 (160,38) から星風回廊 (28,146) へ。星風回廊 (13,146) から潮環 (156,38) へ戻る。

## アプリ構造

`index.html` → `game.js` (UI / pointer / キー / Canvas loop)
→ `world.js` / `silk-world.js` (静的地形 / A* / 世界遷移データ)
→ `camera-limits.js` (bounds / easing)
→ `silk-art.js` / `scenic-biomes.js` / `sprite-srpg.js` (描画)
→ `dialogue-data.js` / `silk-dialogue.js` (会話)
→ `music.js` / `extra-music.js` / `silk-music.js` / `zone-music.js` / `audio.js` (Web Audio)。

HTML, JSはES modulesでroot配信。ゲームのソースが正本で `dist/` は使わない。

## 小さな旅（main統合済みの任意モード）

以前の広い世界 `./?mode=classic` の2世界は維持する。`./?prototype=1` のみ `prototype-world.js` で80×110を切り出し、森と旧港の2地区・4施設・4NPC・北の縦断橋を使う。星風回廊への遷移はない。経路探索では元の164幅の絶対座標を保持し、切り出し範囲外を歩行不可にし、非選択施設の見えない当たり判定を残さない。
詳細仕様、受入条件とPR #7の統合後レビュー依頼は[PROTOTYPE](PROTOTYPE.md)。ミニ版を既定入口へ切り替える案は未採用。

## 操作と基本不変条件

既定の草原湖 `./`（互換URL `./?journey=1`） は [JOURNEY](JOURNEY.md)。112×88の新地形・専用衝突と開始点を持ち、既存の実寸対応A*、Canvas、カメラ、音声を再利用する。円形草原・大湖・塩原・峠・モノリス・白い水辺をループでつなぎ、3地点の任意パノラマと7地域の音楽を追加。以下の通常版・ミニ版の座標、2世界接続、既存資産は保持する。

- 32px論理マス、マス目自体は非表示。目的地タップでA*徒歩、遠方は地図パネル。NPC/施設タップで到着後会話・説明。画面タップで会話進行。
- 移動速度は6.15タイル/秒。小さな足音。カメラは歩行中基本固定、端で滑らかに追従。スムーズな手動パン、主人公が画面から外れない拘束、Issue #30により全モードで手動倍率変更を廃止。草原湖では、Issue #28の採用により場所に応じた自動画角（街3・街道4・広大5）を滑らかに補間する。1/2は将来の近景・屋内用で未使用。
- 地形・湖・構造物は通行不可（各入口は歩行可）。湖はどの拡大縮小でもスマホ1画面に収まらない大きさ。
- 曲は34組×2=68曲（オリジナル/移植曲）。新エリア入域で地域別選曲、初期BGM OFF・SE ON。音切れ対策として先読みと短いクロスフェード、Web Audio操作解禁あり。
- 基本はスマホ縦画面。レイアウトがゲーム座標を予期せずずらさないこと。
