# 旅のカメラと、物語を考える風景

採用根拠：「物語を完成させるイメージを持つ上で必要なもの」「タップしたら主人公側に戻らず、そのまま移動→追いついた後カメラも移動」「倍率の不必要な反復を直す」「見応えのある物体・壮大な風景をヒントとして足す」。基準main：6ecadaf。

## 実装前の技術計画と受入

- 現在の巡礼の通常タップ・地図移動とも、進行方向の前側へ主人公が追いつくまでカメラを保つ。逆向きの先読みや、後ろ側の余白を理由とした引き戻しをしない。移動中の折れ曲がり・停止・行先変更・主人公可視・地図範囲を検査。旧atlas/classic/prototypeは保持。
- 倍率は地域の用途に結びつける。通常0.8、雲上0.46、帝都・最後の器0.38。展望点の小半径で0.8へ戻さない。現在の巡礼だけ、1.6/2.4秒の滞在判定と5秒の保持で境界の出入りを吸収する。Reduced Motionは0.6を上限の引きとする。手動ズームは追加しない。
- 現行の13地域・43区間へ7つの寄り道を追加。生活の便り棚／多段水車／峡谷の高架水道／雲上の円環／陸の船の骨／帝都の配水梁／風の便りの壁。実体は個々の足元だけに置き、既存陸地・通路・入口・人・森市を壊さない。A*、水の通行、速度、保存キーを変更しない。
- 3つの任意遠望で、水道・空の円環・巨大な配水の反復を横の画面にも広げる。外部素材・CDN・音源・新しいタイマーを作らず、可視範囲と既存キャッシュを使う。
- 自動テストに、前へパンした後の引き戻し再現、追いついた後の追従、境界反復で倍率が戻らないこと、全歩行域の接続・全地点往復・描画/実体/開いた通路・遠望を追加。Chromiumで実入力と描画を確認し、CI成功後にPR経由でマージしPagesを確認する。

リスクはカメラの挙動と局所的な衝突配置。主人公を隠して壮大さを作らず、失敗を検査の削除で通さない。自己検査と独立監査、ブラウザ時計と実時間の試遊、音源の検査と実耳を区別する。

## 風景が渡す物語の材料

| 風景 | 歩いて見えるもの | まだ答えない問い |
|---|---|---|
| 便り棚 | 森市のパンや布が他の場所へ渡る支度 | 誰に何を届けたい旅なのか |
| 多段水車 | 生活の小さな器と大設備の同じ分配形 | 維持する人はどこまで責任を持つのか |
| 高架水道 | 人の道より高い水の道、途中から失われた続き | 正確に動く部分と、届かない先の関係 |
| 雲上の円環 | 風と雲が大きな石の切れ目を通る | 何を量って、誰に知らせていたのか |
| 陸の船の骨 | 船の下を人が歩く、保存し直した舟具 | 失った用途を、誰がどう使い直すのか |
| 帝都の配水梁 | 森市の輪や水庭の器が別の規模で反復する | 善意と運用の規模が変わると何が見えるか |
| 便りの壁 | 見た場所の手跡と、続きを描ける余白 | 旅人は帰る、留まる、道を誰かへ渡すのか |

女神の能力、裁き、生贄、滅亡の真相、二地域の過去/未来の同一性は未確定。終わり方の候補も比較用の提案で、クエスト・クリア・セーブ・強制進行として実装しない。楽しい暮らしは、恐怖の種明かしで無効にしない。

## 改善後に試す順路

船着場 → 輪を結ぶ森市（小さな輪、パン、布、住人）→ 北東の風待ちの便り棚 → 水を渡す庭と三段の揚水輪 → 赤い裂け目の街道と高架水路の脚の間／遠望 → 雲上の水尺と円環／遠望 → 列石 → 水を失った七段 → 白い舟の原の船の骨の下 → 宿道 → 分水嶺・閉殿 → 帝都の外郭と分水梁／遠望 → 最後の器の手前、返事を待つ壁。

カメラは序盤の広い道で前へドラッグし、後ろ側に残った主人公の少し先をタップしてから、さらに先をタップすると比較しやすい。Homeを押すのは、明示的に主人公へ構図を戻したい時だけ。水庭の小さな輪と帝都の輪を、音楽ONでもOFFでも比べる。

## 創作上の未採用分岐

- 主人公が便りを届ける旅なのか、受け取る旅なのか。今は誰の荷物とも決めず、持ち物・クエストにしていない。
- 帰還、滞在、次の旅人への引継ぎのどこに重みを置くか。壁の空白は観察物で、結末選択ではない。
- 帝都の共同作業を暮らしとして増やすか、無人でも動く設備の反復に比重を置くか。現時点では運用者や滅亡の答えは書かない。

実機Safari、実耳の音量・地域間のつながり、独立監査、人間の旅情・面白さ・所要時間は未確認。ブラウザの仮想時計で歩行を進める検査は、実時間での人間の試遊と区別する。

## 実装時に見つけた問題

- 従来の画面端追従は、前方へ手動パンして主人公が後ろ側にいると、その余白を理由に構図を戻していた。現在の移動辺の前側だけを追う方式へ変更。通常タップと地図タップで共通にする。前側の静止範囲は画面半幅/半高の45%とし、スマホでも2マス程度のタップで追従を始めない。
- 旧展望点の7/12マスの範囲を出入りすると倍率が戻るため、地域の尺度へ変更。一周を再生する回帰検査では受理倍率は `0.8 → 0.46 → 0.8 → 0.38` のみ。
- 便り棚に共通建築の影を流用すると、実体のない離れた場所に影が出て浮いて見えた。新しい景観は実際の足元に影を描く。
- 分水梁の初期配置は別の街道側につながり、帝都の広場へ戻るのに長い迂回が生じた。帝都の広場側 `(302,158)` に修正。7地点とも指定地域に属し、各広場から100歩未満で到達する回帰検査を追加。

帝都の遠望では、小さな輪に大きな輪用の固定幅を使うと内径が負になり、描画ループが止まる問題も修正した。輪の細部を半径に比例させ、長い巡礼を始める前に3遠望すべての実Canvas描画を検査する。

全44地点・12人・13遠望の往復、全歩行域の接続、既存の43区間、非通行の湖、物体の足元と開いた床を検査する。追加音源や再生設定の変更はなく、既存90曲・環境音・閉殿の静けさを保つ。最終コミットのCI・公開・ブラウザ検査結果は対応PRに記録する。
