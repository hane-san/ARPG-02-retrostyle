# 三つの地続きの旅 — 実装前設計（2026-11-16 / #139）

基点は main `80f7f98`。100枚・15×15・既存の接続と共有境界、裂け目の上端迂回、560ms送り、20音楽エリアを保つ。新しい経路探索・保存・世界切替は作らない。危険度medium（広域の描画と環境音）。

## 構図と共有形状

- 温室：`glass-reflection` → `wet-stairs` → `wet-temple` → `glass-court` → `terraced-fields`。同じ非対称の三角屋根＋小さい換気塔を共通描画する。池では北に頂点と水面の反射、段と受水殿では塀に隠れ、庭で既存の温室の足元に到着。段畑では南の谷に小さい屋根を見下ろす。池にある重複した巨大温室は到着建物との混同を避けるため、既存素材の小さな水盤へ置換する。位置は北向きの景観窓／南を見下ろす谷窓として区別する。
- 風車：`flour-bags` → `white-flower-road` → `cairn-turn` → `mountain-sill` → `glacier-rest`。東の左右非対称の二峰＋鞍部を共通形状で描く。裂け野では手前の岩肩に遮られ、上端の迂回の先から再会。雪嶺では西に小さい同じ風車と丘。裂け野に仕掛けを増やさない。
- 水：分水庭の西 `canal-bend` と北 `empty-basin` → `dry-stairs` → `dry-temple` → `salt-boats`。同じ幅の七段・三つの切欠きの受け皿・水位線を地表の小さな描画として反復。実水域／乾いた溝だけに流れ／水位跡を描き、舟原の舟板は既存素材を活用する。水の由来や神話は確定しない。

描画は既存panoramaの遠景コールバックと盤面の地面／物体層へ挿入。目印の定義・形状・可視画面を小さな専用モジュールにまとめ、往復で状態を変えない。薄い霞は遠景、足元の縁は濃くする。水路の北南境界は同じ中心と岸幅を使う既存のwater線を確認し、必要な対象境界のみ揃える。実水域・溝・崖を救済床に変えない。
