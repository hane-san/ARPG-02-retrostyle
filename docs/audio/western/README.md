# 西側の独自曲・12秒の試聴

全曲はゲームの数値譜面＋WebAudio合成。外部録音／固有旋律を使用していない。
`tests/western-audio-browser.mjs` の `checkWesternAudio(browser, origin, {samples:true})` で、実際のループ生成器から出力した先頭12秒。最後0.5秒と冒頭0.05秒に試聴用フェードを付け、0.7倍にして24kHz・mono・PCM16で書き出す。ゲームはフル尺のステレオループを生成する。試聴ファイルをゲーム中にダウンロードしない。
