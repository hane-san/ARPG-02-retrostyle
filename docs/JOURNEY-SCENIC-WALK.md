# 歩いて楽しい景観とカメラの小さな実験

対象：既定「小さく壮大な旅」176×136マップ ／ 2026-10-22 ／ Issue #50

## 目的
名所を増やすだけでなく、歩く距離と方向、立ち止まる瞬間、視界が開く瞬間に意味を持たせる。「楽しい景色のために歩く」と「歩くから景色が変わる」の両方を試遊する。**設定や超倫理システムの意味は未採用**。

## 実際に追加したもの
- 50超の小景観：港の灯りと旗、草原の種と花、石段の影、峡谷の鈴と岩の刻み、高地の幡、水面の細い光、河畔の灯、玻璃の反射、葦のしなり、白い塩原の石の影、古代碑文の幾何学、遺跡の淡い光など。**衝突なし**。大きな常駐UIを追加しない。
- 12か所の限定的な自動画角地点：赤い峡谷の水尺と出口、鐘楼と港桟橋、水際の広がり、温室街、湿原の学び舎、白い柱列、迷宮の階段など。既存1.8 / 1.35 / 1 / .8 / .6の5段階のみ使用。既存1.2秒滞在・5秒保持を維持。
- 選択式の遠景6つ：円い草原、水位の石、逆流河畔、温室街、湿原、白い柱列。従来の遠景パレットを再利用し音・BGMの切替タイマーは変更しない。
- 4区間だけの控えめな進行方向グライド：峡谷の道、川沿い、白い平原、黒石回廊。**全域追従はしない**。長い連続移動中だけ作動し、画面境界／主人公の視認制約を尊重する。

## 歩き比べのおすすめ
1. 白い港 (19,70)→草原中心 (36,38)：従来の静止中心と布の小さな動き。元のカメラを保つ基準。
2. 裂谷の水尺 (119,25)→朱い谷の出口 (141,42)：寄る画角と開く画角を比べる。
3. 雲際の鐘楼 (158,22)→空の涯 (168,25)：間近で音を想像し、遠くで空の大きさを見る。
4. 河畔 (118,59)→水車 (126,84)→湿原の学び舎 (118,105)：小道のゆるい追従、水辺の反射、近景を比較。
5. 玻璃の回廊 (156,60)→果樹街 (166,84)：建築の近さと生活感の違い。
6. 旧水底の列柱 (155,108)→地平線 (166,127)：大きなものの足元に寄ったあと、急ではなくゆっくり空間が広がる。
7. 左下の迷宮登り口 (48,99)→共鳴石 (60,113)→風台 (65,93)：怖い圧縮と浮遊城の広い遠景を味わう。

## 評価項目
- 景観の密度は多すぎないか。静かな余白は残るか。
- ズームが気持ちよく開閉するか、頻繁な往復や画面酔いはないか。
- ゆるい追従が旅の手触りを良くするか。画面端・手動パン・目的地変更との干渉はないか。
- iPhone Safari縦画面で建物名と景色、主人公が見やすいか。
- 既存ルート、マップからのタップ、音楽の切替、会話、遠望が損なわれていないか。

## 不変・未実施
旧二世界・ミニ版、既定地形の衝突と橋、既存施設/NPC/地域、68曲、操作と音声は変えない。動的な水位低下や年代進行、クエスト、セーブ、物語の真相は作らない。Node / Chromium CIの結果とiPhone実機試遊は別に扱う。mainへの反映は翌15時のClaude監督ランが規則に従って判断する。
