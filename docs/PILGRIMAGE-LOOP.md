# 約10分の巡礼一周と変貌する後半（#80）

## 実装前の技術計画（2026-10-28）

基準main：2013c2a6e39d12c043a5ddad244c9dcbfc5995ef。制作者は現地図の上書き、地形・衝突の見直し、NPCの削減/再配置、多数の造形と色彩/音の実験を採用した。

- 既定のjourneyを編集した一つの旅へ置換する。大きな湖を囲む巡礼道から、帰路の代わりに乾いた水利設備と巨大な拠点へ続く後半を地続きにする。物語やボス戦を作らない。
- 地形は独立したpilgrimage-world.jsへ。480×288、海/湖/岩壁は遮断、橋と道を明示。既存のsilkPathとrouteJourneyWalkを使い、A*や移動速度を変更しない。徒歩5.7/地図7.35。ランドマークの間は広狭・屈曲・水面・岩壁で分節する。
- 約10分は推奨順路の区間距離から歩行時間を算出し、短い観察・調査を加えた8〜12分の設計目安。地図の直行、逆回り、寄り道は自由。一本道のクエスト/進捗/鍵で強制せず、タイマーや低速化で時間を稼がない。人間の所要時間は未検証として残す。
- 地形を見た目と衝突の共通データにする。門の左右/柱/大石は個別の固体矩形、中央床は通行可。全地点の入口、NPC、推奨順路の往復、歩行全域の接続、遮断マスを決定論検査する。
- 描画は新しいタイル/施設モジュール。地域の淡い基調と材質、道端に多数の有限オブジェ、大小の建築/列石/水利を配する。遠くの拠点→中距離の壁→門前の反復で規模を渡す。可視範囲で刈り込み、既存の地形チャンク42上限を維持する。
- カメラは0.8を標準とし、作者指定の大遠景にだけ0.6。既存の滞在/保持/ヒステリシスで切替、主人公可視/前方追従/停止中パンを維持。旧地図の景観座標で新地図が勝手にズームしないよう分離する。
- 原曲68＋追加22曲は全維持。新地域へ意図的な既存曲プールを割当て、後半の色/音/局所沈黙を変える。既存の音合成・クロスフェード・キャッシュ/発音上限・ON/OFF・独立音量を使い、別タイマーを増やさない。
- 旧atlasデータは歴史的比較のため保持し、`?atlas=previous` で検査できる。既存の精密な回帰はその明示した旧版で断言を保って実行し、新しい既定入口自体を別の経路/画面/入力/音/カメラ検査で覆う。classic/prototypeと明示journeyの優先順位は維持する。旧版への切替を通常画面の常設道具へ増やさない。
- 危険度high。実装→check/実ブラウザ→head CI→PR。今回の明示採用による世界再編集であり、過去の座標固定要件を新配置へ無理に当てない。main直push/force/auto-merge/Settings/名前/保存キー/他repo/定期設定の変更は禁止。

## 実装した初稿と測定

- 480×288、13地域、主要13＋小景21の34調査地点、NPC10人、10遠望。
- 道端の有限オブジェは1,335点。旗/花/水鉢/水尺/列石/小段/器/柱/舟/小祠/布/輪の12系統を、土地の色・材質・用途で変える。大きい石/柵/柱/小祠468点は足元に実体を持ち、階段・草花・布などは通行を塞がない。
- 主要な庭は左右の柱それぞれの足元だけ遮断、門は左右の石積みだけ遮断。床を選ぶと歩き、柱などを選ぶと入口まで歩いて調査する。大物の立ち上がりと足元の衝突は別に扱い、床の上で主人公が建物全体に隠れない描画順を使用する。
- 湖水約23,000マス。全歩行域をBFSで検査し、孤立した床は0。全地点・人物・地域中心・遠望の往復と、推奨順路43区間の合法性を検査。
- 推奨順路は合計2,491マス。現地5.7マス/秒で約437秒、地図7.35で約339秒。13か所×10秒＋4遠望×15秒＝190秒を仮の観察量とすると **約10.5分／8.8分**。これは設計計算で、人間の10分試遊ではない。直行は短く、逆回りも寄り道もできる。
- 船着場→草原→水庭→赤い裂け目→雲上の水尺→列石→乾いた七段→白い舟→宿道で湖の周りを巡る。始点のすぐ奥の分水嶺から、閉殿→帝都外郭→最後の器へ。帰路のシナリオやセーブ/進捗ゲートはない。
- 通常屋外0.8。雲上、帝都外郭、最後の器だけ0.6の大遠景。入域4/退出8マスの空間ヒステリシスと既存の滞在/保持/補間で、頻繁な切替を防ぐ。停止中パンと歩行中の先読みを維持。
- 地域の初回選曲は作者指定。水庭/乾いた庭は「器から器へ／同じ溝に砂がある」、列石/閉殿は「触れた後の間／扉のない返事」、帝都は「幾つもの門の向こう」、最後は原曲「最後の防壁」で景観の切迫感を比較する。戦闘は発生しない。閉殿は接近5/退出9マスでBGMだけ静まり、設定を書き換えず復帰する。反復環境音を閉殿や最終拠点へ詰め込まない。
- 原曲68曲と追加22曲＝90曲、保存番号・BGM OFF/SE ON・独立音量を保持。旧atlasの地域選曲/近接音と回帰も保持。
- 全体地図の文字と現在地マークは画面上の大きさを保ち、細い道の概形を表示。地域の正式名はボタンに、短い地名を地図に置く。旅画面へ順番/進捗/残り時間のHUDを増やさない。

## 検査の方法

`npm run check` は従来の全検査に新しい地形/全歩行域接続/衝突/全地点往復/所要時間計算/音/カメラ検査を追加。旧atlasの検査を削らず、音楽の全地域数には新しい13地域を加えて整合を確認する。

`npm run test:browser` は、新しい既定入口の43区間を地図・キー入力で実際に歩く検査、庭の床タップ/柱への調査/キー入力の衝突、遠望、BGMの局所沈黙/復帰、カメラの滑らかな切替、320/390/844pxを追加。長い巡礼の検査はPlaywrightでブラウザ時計を進めるが、主人公座標や地形、速度を変更しない。実時間10分の人間試遊とは呼ばない。

以前のatlasに固有の座標/施設/迷路A-Bは `?atlas=previous` の明示入口で、同じ到着・入力・画像・音の断言を保持して全回帰する。新しい既定入口自体のカメラ入力/配置/Reduced Motionは新地図で検査する。旧classic/prototypeも継続する。結果と対象SHA/CI参照はPRへ記録。

音の発見ジングルも新しい旅に限って抑え、庭・輪・閉殿の調査では既存の小さな水/石/木の応答を使う。巨石や門へ一律の成功音を鳴らさない。SE OFF/音量0と音源上限は既存foleyの契約で保持する。旧atlas/旧モードの音は変更しない。

## マージ前の品質見直し（2026-10-28 夕方）

自由探索を追加点検し、巨石の裏の合法な床で主人公が完全に隠れる不具合を実Canvasの最終ピクセルで再現した。主人公に重なる前景の建築は、形と衝突を保ったまま薄く描画する。端の1マスで不透明度を補間し、前面と開いた床では通常の濃さを維持。カメラ移動や地形変更で隠蔽を回避しない。

小景の選択式が奇数番だけを使い「受け皿11・門10」に偏っていたため、独立した連番で水尺・受け皿・舟・門の4種類を配するよう修正。地点数/大物数/道の距離は変えない。全経路と実際の描画/通行を再検証する。独立監査・iPhone・実耳・10分の実時間体感は引き続き未検証。

小型の門にも大型用の64px柱を描いて通れる中央を覆っていたため、小型では32px（固体の足元1マス）へ合わせる。大型の64px柱は保持。実ブラウザのCanvasで柱の不透明な足元と中央の透明な通路を検査する。
