# 南西の巨大遺跡迷路（2026-10-22 実験実装）

Issue #45 / `feat/45-southwest-ruins-labyrinth`

## 目的と採用範囲
オーナーの明示依頼：「風と湖をめぐる地図」の左下に、世界観になじむ古代神殿と黒いモノリス、強く怖さを感じる半水没の遺構、上った先の浮遊城の眺望を**地続きで、実験的に遊べる形**で実装。下記の歴史解釈・遺跡名・ギミックの意味は**仮**であり、物語の確定設定ではない。

## 試遊ルート
既定入口 `/`（互換 `?journey=1`）で白い船着場 (19,70) → 橋から草原へ → 茶屋近く (46,76) → 南へ風道を下る → 風蝕の神殿 (27,110) → 黒石回廊 (61,113) → 水底の祈り庭 (93,116) → 東側の既存湿原 (120,112) へ回り込み。途中の登り口 (48,99) から、高所の風台 (65,93) へ。風台付近の「雲の上の、届かない城」を任意で開く。西・中央・東を結ぶ迂回路があり、一本の遺跡廊下に閉じない。

## 仕組み
- `journey-ruins.js`：地形・不通行の石壁 R／黒柱 M／浅瀬 U、歩ける石畳 F／階段 K／渡し P、4地域・12調査地点・4人・4眺望。
- `journey-ruins-art.js`：32pxパレット画。遺跡の調査後は灯りが残る。現状「装置を調べた」というセッション内状態のみ（進行フラグや保存ではない）。
- `journey-ruins-vistas.js`：古代遺跡／モノリス／半水没／空中城塞の任意遠望。浮遊城はまだ歩いて渡れる新世界ではなく、先の景色として提示。
- `journey-world.js`：既定世界の左下に追加。`makeJourneyWorld` は2026-10-22のGrok住人追加時に欠落したため、正常版 `f033f01785` の生成処理を復旧し、既存の90住人と従来の地形・施設を維持する。
- 4地域の専用画角（暗い回廊は近景、風台は広い遠景）・既存68曲からの地域選曲。自動ワープ、戦闘、クエスト、セーブ、飛行城への到達は作らない。

## 不変条件・試遊の注意
旧2世界 `?mode=classic`／ミニ版 `?prototype=1` は変更しない。港の元の入江は渡れず、草原へは依然として正式な橋を使う。巨大湖の陸路・水域と旧施設座標は維持する。

`npm run check` および `npm run test:browser` のCIはPRで確認する。iPhone Safari実機での経路タップ、密集マップの視認性、画角変化、音切れ・処理負荷は別途試遊が必要。今後の方向性（採否未確定）：謎の解釈・祈りと旧技術の関係・浮遊城への移動手段・装置同士の連鎖。
