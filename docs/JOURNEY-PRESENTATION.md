# 入口・場所に合う画角・音の連続性（Issue #28）

2026-10-20の人間の明示依頼により、草原湖を既定入口とし、遠景が映える場所と村で画角を変える5段階の演出を採用。main `7135a26` を基準にする。地形・経路・速度・既存保存名は維持する。

## 入口

| URL | 開く世界 |
| --- | --- |
| `./`、`?journey=1` | 草原と湖（既定） |
| `?mode=classic`、`?journey=0` | 以前の潮環群島と星風回廊 |
| `?prototype=1` | 台場ミニ |

明示 `journey=1` → `prototype=1` → classic指定 → 草原湖、の順で判定する。手引きの「以前の広い世界を歩く」から旧2世界に戻れる。旧2世界の橋・施設・NPC・音楽は継続。タイトル・公開パス・設定名の変更や、進行セーブの追加はない。

## 場所に合う5段階

| 目標倍率 | 場所・意図 |
| --- | --- |
| 0.8 | 草原・湖・夕空。地形の広がりと遠さを見せる |
| 1.0 | 塩原。船と周囲の余白を見せる |
| 1.25 | 石の峠。石と山道の関係を見せる |
| 1.5 | 白い船着場、湖畔の小屋の近く。暮らしへ寄る |
| 1.8 | 茶屋の地域。建物や人の気配へ寄る |

`journey-camera.js` が場所の候補へ1.2秒連続滞在してから採用し、採用した場面は最低5秒保持する。地域の境目を少し跨ぐたびに倍率を変えない。小屋は入口から7タイル以内でのみ近景にし、湖全体を村の画角にしない。

5つなのは目標倍率で、切替は滑らかに補間する。拡大縮小時に主人公の画面上の位置を保ち、世界の端と人物可視を再制限する。窓・会話・指の操作中は演出の補間を止める。歩行中の手動ズーム禁止は維持し、今回採用した自動画角だけは歩行中にも移行する。旧2世界・台場ミニのカメラは従来どおり。

＋／−・ホイール・ピンチも草原湖では5段階。自分で調整した画角はその場面にいる間は保持し、次の場面に移ったら演出へ戻る。進行度の保存や段階のアンロックではなく、今いる場所に応じた演出である。

## 音の不連続

実際の `scheduleNote` とOfflineAudioContextで、0.5秒までレンダリングしてから1.1秒の停止を予約すると、修正前のpadは**停止前の波形が最大0.00555変わった**。未来のランプ終点の取消しが、まだ鳴っている音の音量カーブまで変えていた。

`audio-envelope.js` で元の線形／指数カーブを保持し、native `cancelAndHoldAtTime` と未対応・例外時の補償の両方で、停止時刻まで同じカーブを復元する。そこから40msで0へ減衰し、振幅0になってから音源を止める。二度目以降の停止を後ろへ延ばさず、短時間の切替で音を復活させない。通常のharp／drumの終端も微小な振幅から0へ落としてから終了する。

修正後はpad／harp／fluteとnative／fallbackの6ケースで、停止前の最大差は浮動小数点誤差の範囲（7.5e-9以下）、終了後は0。既存のClaude版busフェード補助は保持する。68曲・BGM初期OFF・SE設定・足音は継続。

これは再現した停止・切替ノイズの修正であり、iPhoneの実機負荷やデバイス固有の音割れの解消を測定したものではない。実耳・Safariの判断は試遊へ引き継ぐ。

## 検証・Claude再監査

`npm run check`、`npm run test:browser`、`git diff --check`。追加のNode検査はモード優先順位、5段階と場面保持・手動調整・小屋の範囲・人物可視・フレームレート差、音量包絡線。ブラウザでは既定 `/` の草原湖、旧URLとの行き来、旧2世界の橋、カメラの二本指と回転、徒歩一周で5つの実描画倍率、実レンダリング途中の停止PCMを確認する。最終SHAと結果はPR本文に記録する。

後続Claudeは、新headで次を重点確認する。

1. 場所を歩いて移る時の画角が意図に合い、境界往復で揺れないか。村から草原へ出る広がり、小屋から離れた時の引き。
2. 主人公の位置とマップ端、指ドラッグ、会話中の人物可視、移動中の手動ロックと演出の例外が整合するか。
3. 長音の停止、曲の切替、短時間OFF/ON、音量変更、背景復帰でノイズや古い音の復活がないか。
4. 旧2世界とミニ版の入口・往復・UIを保持したか。

独立監査は後続Claudeへ引継ぎ。iPhone Safari実機・実耳・WebKitは未検証。人間のマージ後に公開URLの既定入口と音声を確認する。
