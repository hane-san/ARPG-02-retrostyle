## 試す

この変更を含むブランチで `npm run dev` を実行し、**http://localhost:4173/?journey=1** を開く。Issue #28以降の既定入口 `/` も草原湖。以前の2世界は `/?mode=classic`、台場ミニ版は `/?prototype=1`。操作説明（⋯）から3モード間を移動できる。`journey=1` と `prototype=1` の両方が指定された場合は新マップを優先する。

PR #15はmainへ統合済み（`14ea85b3fdceb6a730e1da462816f10d0e96275d`）。[公開版の草原と湖](https://hane-san.github.io/ARPG-02-retrostyle/?journey=1)から遊べる。今後の未統合ブランチを試す場合だけ、同じLANのPCでサーバーを立て、`http://PCのLANアドレス:4173/?journey=1` をSafariで開く。`localhost` はiPhone自身を指す。公開への統合とiPhone実機受入は別であり、後者は未検証。

## 地理と歩行

112×88＝9,856マス。星風回廊430×270の面積の約8.5%で、原図を切り取ったものではない。32px論理マス、歩行速度6.15マス/秒、タップ経路、ドラッグ、移動中ズームロックを再利用する。新マップには旧世界へのポータルを置かない。

| 場所 | 配置・役割 |
| --- | --- |
| 白い船着場 | 開始(19,70)。折屋根の連絡舎、海辺の灯り、実際の水路を渡る連絡橋。帰る場所。 |
| 円い風の草原 | 中心(36,38)、半径24.5。円周の内側に半径22.2の周回道。真ん中は広く空け、右回り・左回り・横断を選べる。 |
| 空をしまう湖 | 中心付近(81,52)、約47×35。水は歩行不可。北岸と南岸の両方を回れる。 |
| 海の記憶の塩原 | 北東の白い乾燥盆地。船を残し、峠道と湖の東岸を接続する。 |
| 石影の峠 | 岩壁が道を曲げる。通れる石道と草原の周回道をつなぎ、山腹の「名のない石」へ近づく。 |
| 水路のチャイハナ | 湖の水路、畑、茶屋。南の水路橋は帰路にも使える。 |

6施設・4NPC。海の連絡舎、茶屋、湖畔の小屋という少数の暮らしを水と交易路に結びつける。地名、会話、景観説明は**仮テキスト**で、`journey-world.js` 内で差し替え可能。主筋・真相・戦闘・クエスト・進行セーブは決めていない。

地図は地形と地域名、主人公を示す。未訪問施設の全位置や物語の回答を一覧表示せず、施設マーカーは連絡舎と訪問済みだけを表示する。地図上の建物を選ぶと入口まで歩いて説明を開く。

## 景色を広く見せるUI

同日の追加依頼「メニューは下に集約」「上はスッキリ」「会話やウィンドウが旅を妨げない」「作風に合う色」「メタ表記は不要」を新モードに反映。`journey-ui.js` が既存のボタンとイベントを再利用して下部へ移し、`journey.css` を新モードだけで読み込む。

- 上部は全面が探索フィールド。現在地・任意の遠望と、地図／音楽／自分へ／縮小／拡大／手引きを下にまとめる。発見数、コンパス、操作の常設テキスト、地域移動時の通知を表示しない。
- 紙の生成り・灰緑・青緑を地図、音楽、会話、遠望に統一。遠望の入口は小さな文字リンク。主要6道具は320px幅でも横幅44px以上を確保する。
- 会話は短いカードを基本的に下部へ置く。主人公が下端にいるときは一時的に上側へ置き、話している人を隠さない。本文や「つづき」で読み進めるほか、地面のタップ・移動キー・下部の道具で閉じて次の操作へ進める。既に隣にいるNPCや再訪した施設の即時会話も、そのタップで消えない。
- 窓は下部道具を覆わず、同じ道具で閉じたり別の道具へ直接切り替えたりできる。Escape／×で閉じるとフォーカスを戻す。横画面の地図は地図と行き先を左右に並べる。高さは実際の下部領域とsafe areaに追従する。
- 通常版・台場ミニ版のUI、会話をどこでもタップして進める操作は維持する。

## 見せ場と音楽

`journey-art.js` の専用パレットと地形描画、白い折屋根、巨大な一枚の石、静かな船を新設。岩は個別の石柱を乱造せず、一続きの山体として描く。既存の灌漑地形、主人公・NPC描画、橋、Canvasのチャンクキャッシュを活用する。

船着場・石の峠・南岸の3地点では「遠くを眺める／夕空を眺める」を表示。夕空・重なる山・湖の光・小さな旅人のパノラマは任意に開閉できる。×・Escape・地図を開く・歩き始めると閉じる。強制カットシーンや自動ワープはない。

音楽ライブラリは既存68曲のまま。7地域それぞれに3曲を割り当て、草原の弦、湖の笛、塩原の余白、茶屋のハープ、峠のホルン、夕景を区別する。`journey-music.js` は以下を満たす。

- 場所名は即時更新し、選曲は新地域に**2.2秒連続滞在**してから。
- 地域選曲は**12秒以上保持**。途中の候補は最新の連続滞在地域へまとめ、元の地域へ戻れば破棄する。
- 停止中も候補を更新する。待っている間や同じ地域では音声を再始動しない。
- 手動選曲は次の地域選曲まで有効。既存240msクロスフェード、BGM初期OFF・SE初期ON、利用者操作による音声解禁、`tidal-atlas:` の設定をそのまま使う。

地域の選曲を変更したことと、iPhone実耳で快適と判断できたことは別。後者は人間の受入待ち。

## 技術計画・不変条件（high相当）

`journey-world.js` が独立したtiles・occupied・start・施設・地区を持つ。既存 `silkPath` は渡した `world.w/h` で索引・復元するので、新モードの `world.findPath` として再利用する。旧 `findPath` の164幅やミニ版のクロップ索引は使用しない。旧 `world.js` / `silk-world.js` / `prototype-world.js` のデータ・経路処理は変更しない。

歩行可否は整数かつ実寸内で、水・浅瀬・岩壁・施設の占有を除いたマスだけ。新モードの途中目的地変更は現在の辺の次のマスまで進んでから経路を切り替え、斜めの角抜けや座標の飛びを避ける。既存2モードの歩行ロジックは維持する。

確認すべき条件は、全歩行マスが開始点から接続していること、全施設・NPC・地域ボタン・遠望地点へ往復できること、水・壁・施設内へ経路が入らないこと、草原の左右半周と湖の両岸に代替経路があること。静的カメラ・表示範囲と音声合成の基盤には手を入れない。
