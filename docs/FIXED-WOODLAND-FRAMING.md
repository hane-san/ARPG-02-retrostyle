# 木々・小物と上部景観の調整 — #146（2026-11-17）

## 実装前の設計

基点はmain `1aea0e97060d28cd3cbc0c11953b61421710b223`。画面切替アトラスを対象とするmedium変更。持ち主から、木々や小物の硬すぎる輪郭を幻想的な美しさとレトロな温かみの釣合いへ調整し、不自然な塞ぎ方と上画面の景観を点検して、マージまで進めることを採用された。

- 全100画面を390px縦の同じ条件で描いて点検する。これは診断用の実レンダラー描画として記録し、通常タップで歩いた実画面と区別する。
- 木々は画面切替版に限定した描画へ。枝ぶりと葉の塊を座標由来の安定した形で描き、均一な三角形・楕円・反射の反復を減らす。輪郭を黒く囲わず、緑や樹皮の色、葉の影、小さな明色の点で立体感を出す。元の固体の足元と種類を保ち、人物・出口を覆う樹冠の扱いを明瞭にする。
- 小物は材質に合う細い輪郭を使い、明色や影の大きな一律の縁を控える。主要な建物・遠景の共通目印・主人公は個別の描画を維持する。
- 周囲の茂みや樹冠が歩ける道へ大きく被さる部分を点検し、既存の非通行セルに根ざした自然な境界へ整える。見えない壁を作らず、水・崖・固体と床を絵で読み分けられることを優先。
- 上部の隣盤面を近い大きさで切り取る表示を点検する。縦画面では遠景と手前の道に奥行きを持たせ、隣の設備や固体の断片が大きく覗く構図を抑える。往路・復路・スライドの両端を揃え、高い塔や風車など現在地の建物を切らない。
- 床・水・固体・入口・共有境界・接続・目印位置・NPC・音楽・保存を保つ。経路基盤は新設せず、つながった世界と旧モードの描画も変更しない。

## 100画面で判明した問題と修正

- 細長い木は均一な楕円、針葉樹は同じ三角形、周囲の森は同心円の連続に見えた。アトラス専用の `fixed-nature-art.js` で枝ぶり・不規則な葉の塊・小さな光の点へ整えた。輪郭は素材色。ぼかしや全画面フィルターは使わず、座標と既存seedから形を固定する。
- 森の縁の葉が細い道へ大きく張り出し、元の幅より狭く見える箇所があった。低木と樹冠を既存の非通行セルから2pxまでに収め、境界を自然な葉と下草で示す。固体の幹や岩の足元は元の位置・範囲を保つ。
- 近い人や出口のために木全体が透けていた。人と矢印を覆う周りだけ葉を薄くし、他の枝葉の量感を残す。Canvasの量子化誤差を除き、その外側のアルファが変わらないことを描画検査する。
- 受水殿・水路・裂け野・雪嶺などで、北隣の下部が近い大きさの石段・崖・壁として上部に帯状に覗いていた。縦画面は別盤面の切抜きを描かず、実際の道・橋・石段の幅と一致する短い道を先細りに霞へ続ける。広い草地の出口全体を光の扇のような道にせず、同じ細い水路が境界に続く場合も中心を保つ。横画面の隣接風景は残し、移動中は前後の現在地を既存のスライド層で描く。
- 近景の模様が空の下で硬い帯として始まっていた。模様そのもののアルファを遠方で落とし、丘の輪郭が残るようにした。温室の屋根・二峰と鞍部・遠い風車、塔や分水梁など高い現在地の設備は別層のまま保つ。
- 水辺の設備として描かれた2本の木も平たい傘のようだった。`west-lane` / `west-impression` / `west-dots` はアトラス内だけ枝と垂れる葉、元の位置の腰掛けへ整えた。小物・家・設備には石や木の細い材質色の縁を使い、人物の濃さは維持した。
