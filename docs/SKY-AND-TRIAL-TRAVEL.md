# 空を見上げ、土地を歩き比べる — #110

採用：2026-11-04。基準main `5a6ebb3`（#109）。制作者は各地の美術密度・自然で個性的な地形、緩急と格好よさを持つ曲、出発点の試遊ワープ、特に空の色と描写を依頼し、本件の通常PRマージまでCodexに委任した。

## 技術計画と実装

1. `landscape-sky.js`。西の七つの空と元の雲上の空を、世界の座標で描く。高度に沿った五色の空気、太陽の光、厚みのある雲・雲底の陰と光る縁、三段の霞、雪の谷を重ねる。山・雲・地平線の形を画面の縦横で引き伸ばさない。崖道だけ累計3分の昼夕、風車丘は金・桃・紫の夕色、遠原は青緑と白い光。動きは小さく、Reduced Motionでは雲の揺れを止める。
2. 空は実際に通れない空のセルの奥に描く。前景地形と建築が遮蔽する。世界の開口の最後の列も覆い、黒い隙間を作らない。雲上の北は元のXだけを透明な空へ変え、元の湖や床は変えない。風車丘・集落・遠原などは道・建築・住人を守って、背後の崖縁を不規則な形にする。既存の画角と歩行カメラは保つ。
3. `landscape-geometry.js`／`pilgrimage-landforms.js`。土地ごとに斜めの丘、くびれた尾根、湾・岬、曲がる林間、湿地の枝を使う。西の外周道を二本の長い直線から曲がる国道へ替え、下流の回遊も残す。元の巡礼は、既存床・水・建物の足元を変えず、道沿いのXへ接続した小さな岩棚や林間を広げる。元の43区間・2,485マスを維持。
4. `regional-detail.js`と自然物の描画。土地のまとまりに沿った草・花・落葉・苔・石・浅瀬の跡、幹と根、葉の光と陰、道端の荷物・灯・水尺や設備を描き分ける。水庭と干上がった土地では同じ設備の形を使い、色・中身・濡れ跡を変える。床の薄い印は歩ける素材模様、立体の足元は既存の固体を正本にする。静的面はチャンクへ、自然物は可視範囲へ絞り、42チャンク上限を維持する。
5. `energy-music.js`。旧106曲の譜面・イベント・IDを完全保持し、新4曲だけ追加。独立した旋律・応答・和声、リフ、低音と小さな打楽器、静かな導入／展開／間奏／山場／余韻を持つ。新音色pulseも停止時のゲイン連続性を守る。既存フェード・BGM OFF・SE ON・独立音量を維持。
6. `trial-travel.js`。試遊の道標は(25,104)から3×3、入口(26,107)の平らな模様。船着場でタップし、入口まで歩いてから「ランダムに飛ぶ」を選ぶ。西12＋南東4＋森市・裂け目・雲上の19候補を袋で抽選する。通常の一巡では重複せず、直前の土地を避ける。到着後も別の土地を選べ、閉じれば歩ける。手引きから道標へ戻れる。経路・予約・パン・追従を消し、床・カメラ倍率・地域名・地域曲・無音状態を同期。明示した試遊移動だけの例外であり、女神の力・儀式・クエスト・セーブではない。旧モードと常設の四操作は変更しない。

全体は480×832、33地域、87地点（試遊の道標1を含む）、32人、110曲。道標は発見数に加えない。古い地域・曲は削らない。

## 試してほしい順路

1. 船着場の左、淡い輪の道標へ歩いてタップ。「ランダムに飛ぶ」で土地を選び、閉じて数歩歩く。手引きの「試遊の道標へ戻る」で戻ってまた試す。同じ土地ばかりにならないことを比べる。
2. 雪嶺・風車丘・空の集落・遠原では、停止して少し北へドラッグして空を見る。縦横を変え、山や雲の形と地形の遮蔽を比べる。雪嶺では滞在して青から夕暮れへ。
3. BGMをONにして登山路→裂け目→風窓台地→草原を聴き比べ、導入から山場まで待つ。温室・遠原・海岸へ移って、静かな曲との違いも比較する。
4. 道標を使わず、森市→水庭→裂け目→雲上、風車丘→段畑→登山路→遠原、河港街→葦原→海岸を往復。曲がる地形・川岸・入口・足音を比べる。
