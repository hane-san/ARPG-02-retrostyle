# 小物・会話・近接音の試作（#51 / #53）

## 実装前の設計

最新main `2322ea4`（景観PR #52、配置PR #56統合後）を基準とする。
既存の `kind: art`、到着後の会話、描画、発見数からの除外を再利用し、
12個の2×2の小物を12地域の施設近くの乾いた余白に置く。通路や橋を塞がず、
水域・経路探索・入力・地形生成のアルゴリズムは変更しない。
既存NPC12人には元の説明を残したまま生活上の短い一言を加える。

近接音は既存 `createJourneyFoley` のAudioContextとmaster音量を共用する。
純粋な距離制御器が半径5マス／退出6マスのヒステリシスと最低3秒の間隔を持ち、
同時2音源・合計距離gain 1以下を返す。短い原創合成音だけを鳴らし、
既存の全体6声制限に含める。再入域・復帰時に過去の発音を追いかけない。
発音中も距離gainを補間し、会話・メニュー・遠望・背景化・SFX OFFでは静める。
AudioContextを距離判定から作成・resumeせず、既存のユーザー操作だけで解禁する。

危険度medium（配置・合成SE）。保存形式・キー、68曲、選曲、カメラ、旧モードは不変。
全件の陸地・到達性・入口・重なり、距離境界とミュート・声数、実ブラウザの
接近・離脱・再接近を検査する。実機聴感と楽しさ・電池消費は未検証として渡す。

## 実行結果

- `npm run check`：24テストファイル成功、失敗0。既存の人数・地形・文字量などの検査は維持。
- `CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser`：全成功。
  実際の地図→徒歩→小物会話、接近→離脱→再接近、SE OFF、旧モード、カメラ、
  景観が建物に埋まらないこと、68曲と追加曲、PCM連続性まで確認した。
- PCM：10種類の近接音について無音でないこと、振幅・DC・隣接サンプル差、
  無音の始終端、声の解放を実際のOfflineAudioContextで確認。実耳とは別。
- Chromiumで12個の小物を描画した一覧と、港・茶屋・塩原などの画面を目視確認。
  スクリーンショットはローカルの検証用で、コミットしない。
- Node 24.19.0、system Chromium。GitHub ActionsのNode 22 / ChromiumはPRで確認する。

ブラウザ検査の最初の実行は、既存の設定保持検査がSE OFFを残したため、
追加の「発音あり」検査が失敗した。事前にUIでSE ON・BGM OFFへ設定して再実行し成功。
テストを削除・スキップせず、設定保持の既存検査も維持した。

iPhone Safari、実耳での5系統の違い・音量、電池消費、低性能端末、人間の楽しさ、
独立監査は未検証。茶屋・港・塩原・高地・黒石を訪れ、会話中は静まり、
離れて戻っても連打しないか、空の涯の椅子の無音が残るかを夕方に試す。
